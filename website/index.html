// features

Built for developers who ship

Every feature earns its place. No sparkle, no lock-in.

01

Conversational Planning

Not a one-shot prompt dump. Approve, revise, or tweak the plan in plain language before anything runs.

assumption dial scope assessment dual-fidelity plans
02

Text Protocol

XML-like tags parsed by Relay — not native function calling. Works with any model. Built for transparency.

<read> <edit> <apply_patch> <bash>
03

Multi-Provider

Pair a smart brain on Claude with fast hands on Haiku or DeepSeek Flash. Independent provider per role.

OpenRouter DeepSeek custom endpoints
04

Interrupt & Steer

Esc interrupts mid-run without destroying your session. Type to steer, queue the next task, or stop.

/queue /redirect up-arrow recall
05

Safety Rails

Read-before-edit guard, command policy for bash, loop breakers, bounded budgets, and step review.

BLOCKED CONFIRM ALLOW
06

Live Telemetry

Per-role token counts, cost, and latency. Session-cumulative cost counter. Run history in .relay/runs.jsonl.

/cost /log relay doctor
// executor tools

First-class tool protocol

Every tool is a text tag. Parsed by Relay, never provider tool-calling.

<read>Explore files
<list>Directory listing
<grep>Search codebase
<edit>Full-file replace
<write>Create/replace files
<apply_patch>Multi-hunk patches
<glob>Path patterns
<mkdir>Create directories
<bash>Shell commands
<webfetch>HTTP GET → text

// quickstart

Up and running in 60 seconds

1

Install

pip install relay-cli
2

Configure

cp .env.example .env

Add your OPENROUTER_API_KEY or DEEPSEEK_API_KEY

3

Launch

relay tui

Or run headless: relay run -g "your goal"

From source:

git clone https://github.com/HardCoreGamer969/Relay.git && cd Relay && pip install -e .
